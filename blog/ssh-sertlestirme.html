SSH Sunucunu Sertleştirmek: Şifreyi Bırak, Anahtara Geç

İnternete açık bir Linux sunucunun ilk saldırı yüzeyi neredeyse her zaman SSH olur. Birkaç ayarla bu kapıyı ciddi şekilde sağlamlaştırabilirsin.

1. Anahtar tabanlı kimlik doğrulama

Parola denemeleri (brute force) SSH’a yönelik en yaygın saldırıdır. Parolayı tamamen kapatıp anahtar kullanmak bu saldırı türünü büyük oranda etkisiz bırakır. Kendi bilgisayarında bir Ed25519 anahtarı oluştur ve sunucuya kopyala:

ssh-keygen -t ed25519 -C "kullanici@laptop"
ssh-copy-id kullanici@sunucu-ip

Özel anahtarını (id_ed25519) kimseyle paylaşma ve mümkünse bir parola (passphrase) ile koru.

2. sshd_config ayarları

/etc/ssh/sshd_config dosyasında şu ayarları gözden geçir:

PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
KbdInteractiveAuthentication no
MaxAuthTries 3
LoginGraceTime 30
AllowUsers kullanici
X11Forwarding no
ClientAliveInterval 300
ClientAliveCountMax 2

Yapılandırmayı kontrol edip servisi yeniden yükle:

sudo sshd -t
sudo systemctl reload ssh   # RHEL tabanlı sistemlerde: sshd
Dikkat: Ayarları uygulamadan önce açık bir ikinci SSH oturumu tut. Hata yaparsan kendini dışarıda bırakmazsın. Anahtarla giriş yapabildiğini doğrulamadan PasswordAuthentication no yapma.

3. Güvenlik duvarı

Sadece ihtiyacın olan portları aç. UFW ile bu birkaç satırdır; SSH kuralını etkinleştirmeden önce eklemeyi unutma:

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow OpenSSH
sudo ufw enable

4. fail2ban ile otomatik engelleme

Tekrarlayan başarısız denemeleri yapan IP adreslerini geçici olarak engeller:

sudo apt install fail2ban

# /etc/fail2ban/jail.local
[sshd]
enabled  = true
maxretry = 5
findtime = 10m
bantime  = 1h
sudo systemctl enable --now fail2ban
sudo fail2ban-client status sshd

5. Port değiştirmek yeterli mi?

SSH portunu 22’den değiştirmek log gürültüsünü azaltır ama gerçek bir güvenlik önlemi değildir. Hedefli bir saldırgan tüm portları tarar. Bunu ek bir katman olarak düşün, anahtar kimlik doğrulamanın yerine koyma.

6. Doğrulama

Etkin ayarları sshd’nin gerçekte nasıl yorumladığına bakarak doğrula:

sudo sshd -T | grep -E "permitrootlogin|passwordauthentication|pubkeyauthentication"

Özet

  • Parola yerine anahtar kullan, root girişini kapat.
  • Erişimi AllowUsers ile sınırla.
  • UFW ile yalnızca gerekli portları aç.
  • fail2ban ile saldırı denemelerini otomatik engelle.
  • Her değişiklikten sonra ayarları test et.

Bu yazıdaki komutlar ve yöntemler eğitim ve savunma amaçlıdır. Yalnızca sahibi olduğun veya yazılı izin aldığın sistemlerde dene. Komutları üretim ortamında çalıştırmadan önce bir test sisteminde dene.
